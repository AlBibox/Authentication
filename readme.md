If you wanna work on this project and enhance it or test it you need to enter in backend folder and start it with npm run dev, if you wanna build backend you can use npm run build and if you wanna run builded code you can use npm run prod. 

The backend is serving the frontend builded in the build folder but you can also launch frontend dev server if you wanna work on frontend go in front end folder and there you can launch dev server with npm run dev or build the frontend inside dist folder with npm run build.

You also need to set up .env for backend with db configuration and for frontend with the api endpoint used in production. 

If you want to try the authentication you can at this address https://authentication-bice-rho.vercel.app/ the only problem is sometimes the db is down.
